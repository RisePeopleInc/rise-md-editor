# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][covenant] as a
statement of community expectations for issues, pull requests, and
discussion threads.

- Canonical text: <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
- Source: <https://github.com/EthicalSource/contributor_covenant>

## No formal enforcement

This project is provided as-is and maintained on a best-effort basis. There
is no dedicated moderation team, no formal reporting channel, and no
escalation process beyond what GitHub's platform itself provides.

Maintainers may take action on issues, pull requests, or discussion
threads at their discretion — including editing, hiding, locking, or
removing content — but make no commitments about response time, outcome,
or notification.

For platform-level abuse or harassment, use GitHub's own reporting tools:

- [GitHub Community Guidelines][gh-guidelines]
- [Reporting abuse or spam on GitHub][gh-report]
